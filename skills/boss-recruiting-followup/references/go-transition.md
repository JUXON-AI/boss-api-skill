# 当前岗位Go转向与实践信号

用户明确要求当前岗位筛问候选人是否愿意转Go，可以从零开始学习。在剩余实质轮次中询问缺项，例如“这边需要转Go开发，可以从零学，你能接受吗？”本人已有明确接受时不重复问；“会Go”不自动等于接受当前岗位安排。有明确拒绝则记录当前岗位不匹配，不以缺少现成Go经验直接拒绝愿意学习者。

分别记录具体Go实践、仅了解、愿意学习及未知。只有本人明确的Go功能实现、项目职责或其他可归因开发证据才作为单独正向能力信号；只了解、愿意学不加能力分。绑定本人UID、原话mid或身份绑定简历来源。未配置数值权重时不自行增加分数，不混入竞赛/GitHub证明分，不用语言名堆叠重评既有技术分。

后续新入库须核清岗位Go转向接受情况。适用于新增授权之后的未完成筛选，不重建已入库记录或补发既有HR交接。已达两轮且Go意愿未知者等待主动新证据，不借新规则发送第三轮；人工接续和原暂停保持。Go目标仅限本岗位，不扩为全公司技术栈或培训承诺。
