# Claude Code接入方式追问

候选人本人提到用过Claude Code且方式未明确时，在剩余实质轮次内优先自然问：“你用Claude Code是走中转站，还是用自己的账号？”已有答案不重问；“Claude”“CC”或普通API用法不自行扩成Claude Code。按本人UID、mid和原话区分中转站、本人官方账号、组织/共享账号及未知；自有中转API key不等于本人官方账号。

用户偏好本人官方账号，作为单独的正向评价项保留自述来源。没有指定数值权重时不擅定分数、不更改确定性评分公式，不混入竞赛/GitHub证明分、能力覆盖或入库硬门槛。中转站或未知不因此扣分或拒绝；账号归属不证明使用熟练度、付费档次、收入或当前可用。已封禁、退款等原话同时保留，不称账号仍可用。不索要账号ID、密码、token、账单截图或登录演示。

这是实质工具使用澄清，不是政策答复。保留两轮上限、原暂停和人工接续；不额外第三轮、不单为补问接触已HR者，不批量重写历史分数或补发旧消息。提案仍须主代理按本人原始证据验收。
