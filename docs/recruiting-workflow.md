# 招聘流程（实习 / 全职）

AI帮忙看资料、聊关键问题、整理给HR；HR和用人负责人决定面试及录用。具体流程见 [流程图](recruiting-flowchart.md)，常见说法见 [58场景语料模板](hr-corpus-template.md)。

## 先确认岗位

运行前，Agent先检查当前机器的REA、lark-cli和飞书skills，缺少时按授权补齐部署。同步人才库需要用户身份的飞书授权；没有有效登录态时，由Agent展示链接和二维码，用户用飞书扫码确认，Agent继续完成登录并核验目标人才库。机器人可用不等于用户已登录。已有有效授权则直接复用，不要求重复扫码。

HR先确认岗位类型、实际职责、工作地点和方式、预算及必须条件。全职月薪和实习日薪分别填写；模板里的100–120元/天及15–25K/月是示例，不是其他岗位的待遇承诺。

## 看资料，再聊两轮

AI结合当前简历、附件和已有聊天，记录“已确认”“候选人自述”“还不清楚”，已经说过的不再问。简历资料卡、在线摘要和PDF分开看，读取不到的内容不补写。

| 沟通 | 实习 | 全职 |
|---|---|---|
| 第一轮 | 掌握的技术和工具、本人负责功能、可独立完成范围；相关比赛获奖可单列证明加分，可主动补充公开 GitHub 贡献；不要求验证或做题 | 相关经历、独立负责范围与实际交付；围绕岗位补关键能力证据 |
| 第二轮 | 日薪、地点、每周出勤、实习月数、学校手续、到岗日 | 期望月薪、在职状态、交接周期、地点/办公方式、职级方向、入职日 |

首次开场直接用“你好”，不加用户名。实习生问清能力后评分：基础能力分与证明加分分开，未知项保持待了解，自述获奖如实注明；不布置代码验证、测试或证书核验任务。竞赛按国家级、省级、校级和名次计证明加分，自述证据暂按折扣计入；候选人主动给出 GitHub 时，只读核对本人 commits、fork 相对上游的真实贡献、合并 PR、测试或演示，纯 fork 上游代码、空仓库或无法归因的提交不计分。证明加分封顶，且不能拯救未知基础分。每次抓关键问题，最多两轮实质沟通。两轮后还有缺口，就整理交HR，避免持续盘问。候选人有其他offer时，按需确认其决策截止时间，不让对方拒掉其他机会来等我们。

## 先初筛，再交接

初筛通过的，写入飞书当前岗位人才库，HR状态保持待复核；信息不足或条件冲突的先交人工判断，不能伪装成通过。评分只是辅助，不能代替真人决定，更不能自动拒绝。

表里整理岗位、薪资、姓名、院校、能力与岗位匹配证据、最近联系时间、最快到岗日、简历链接和待确认项。已有的人口信息只据实记录、不推断，不作为与岗位无关的评分依据。院校分类和能力评价分开。

入库并完成实际交接、回读核对后，收尾说“你的相关信息已转交给人事 HR 进一步处理，有消息会第一时间在 BOSS 上联系你”。符合下方邮件条件时可以增加发送简历时使用的邮箱；已有收尾不重复补发。后续渠道、时间和结果按真实状态同步，不保证面试、offer或邮件必达。

收尾默认用“后续有进展会在 BOSS 上联系你”。如果已在招聘方飞书邮箱收到该候选人的简历邮件，并核对了 BOSS 身份和当前岗位，则用“后续有进展会通过 BOSS 或你发送简历时使用的邮箱联系你”。邮箱以匹配来信的发件地址为准，不能只因为简历填写了邮箱就采用；关联证据留在本地私有记录，邮件实际操作遵循 `lark-mail`。

HR看表后选择面试、暂缓或不推进。面试官与用人负责人给出结果，HR按批准内容发正式通知。当前岗位不合适而希望后续保留资料的，先征得同意、另标用途，不写成当前岗位初筛通过；候选人退出则停止后续联系并处理资料请求。

## HR如何教AI说人话

在语料模板中找到相应岗位类型和场景，把自然说法填进“HR实际说法”，核对事实与承诺后改为“启用”。待确认、停用或实际说法为空的条目不能视为批准口径。没有启用语料时，AI先出待审草稿。

AI参考语气和结构，每次仍要核对本人的事实；这不是模型自动训练，也不把每一条已发送消息自动写成通用话术。

## 多个Agent怎么分工

每个人的材料可以交不同subagent研究，但每个候选人必须有一份独立的本地状态记录，绑定岗位哈希、最新完整历史指纹、证据、确定性评分、沟通轮次和下一动作。subagent只收到岗位和本人的一份记录；主Agent用记录哈希做乐观锁更新，批量后统一校验。发消息时排队，每次只发一人；发前重新读取身份和最新聊天，发后回读确认唯一新增记录。结果不明先检查，不换脚本重发。任何记录冲突、历史变化或重算不一致都停止，不靠长对话记忆补齐。

本仓库的技术skill负责接口，招聘skill负责上述流程。Mac 与 Windows 的验证边界见根目录报告；Windows已有三个两轮沟通至人才库待HR复核及BOSS交接通知的限定实测样本。邮件、附件、全量分页及面试录用后续未证明。复制流程文档不会自动获得候选人发送授权。
